- 《锐之博班级管理手册.pdf》用于出勤、作业、家校反馈和接送记录；表格中空白的时间栏不补造为统一作息。
- 《安全卫生管理.docx》用于环境、活动、路队、就餐、午休及日常卫生内容。不从该材料扩展未经核实的急救、用药或消毒配比操作。
- 培训 MVP 规格说明、现有培训代码及 `docs/teacher-training-rollout.md` 用于核对七门顺序、章节、测验、实操与安全确认机制。旧需求问卷中的选项不覆盖后续 MVP 和当前系统规则，也不作为人事制度依据。
- 每课末尾的“来源与审核事项”列出实际采用位置、未确认口径及改编说明。没有采用的文档不能视为已完整审定；本轮未把独立 `.xls` 作息表、所有 PDF 附图或全部旧问答逐项编入课程。

原始文件只读保留。来源中的旧话术、矛盾描述和不适当做法没有无条件转成标准答案；保守改编和排除事项在各课说明中保留，供业务负责人决定正式表述。

## 需要负责人审核的事项

1. 人事负责人逐条复核薪资适用对象、构成、结算口径与晋升条件。用户已确认手册现行，但未写明或互相冲突的条款仍需补充；涉及奖惩及劳动权益的内容不得因本稿引用而视为完成合规审查。
2. 教学负责人复核作息、批改标准、积分管理、沟通频次及实操合格标准，确认适用于实际校区和年龄段。
3. 安全负责人确认接送授权核验、失联或受伤等异常的应急预案、联系渠道、隐私授权和现场演练安排。学生协助不替代成人监护；不以熟人身份或孩子口述代替有效交接授权。
4. 内容负责人确认各课预计与最低时长、测验及格分和最多尝试次数。JSON 中的时长和及格分是编辑建议，未设置 `maxAttempts` 表示不限次数，不是已批准制度。
5. 按章复核每道题的答案能从正文得到，确保干扰项没有歧义；用脱敏情景演练实操清单。各课的具体待确认项见 `review.pendingDecisions`，处理完后更新草稿并完成业务预览，再考虑启用。

## JSON 的用途

同名 `.json` 是与现有接口字段对齐的结构化审核底稿，外层分为：

- `review`：资料来源、用户确认、待确认事项及编写说明，不属于课程接口字段。
- `course`：完整课程编辑数据，包含 `status: "draft"`、章节 `contentHtml`、`quiz` 和 `practicalItems`。

JSON 不含数据库 ID、线上账号信息或媒体文件 ID。本地 JSON 保留最初审核底稿的 `status: "draft"`，不代表线上当前状态；线上七门课程已按后续授权启用。章节 `isEnabled: true` 是章节级设置。当前为纯文字内容，所有章节 `media: []`；没有制作或上传图片、视频。不要用本地底稿直接覆盖线上状态或后续人工修改。

后台目前没有 JSON 批量导入按钮，不能把外层 `review` 连同 `course` 直接提交接口。本次采用用户明确授权的一次性维护操作，仅填充已核实为空的七门线上草稿，并非新增通用导入功能。今后重新导入或覆盖已有内容仍需重新核对目标环境、线上编辑、业务审核与授权，不能直接重放本次操作。
