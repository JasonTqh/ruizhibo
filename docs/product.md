# 产品规格：锐之博托管中心系统

## 1. 产品定位

本系统服务托管中心日常运营，围绕“老师记录过程、家长查看动态、管理员维护基础数据”建立闭环。

孩子不作为登录用户存在，只作为 `student` 业务实体；实际使用者是家长、教师和管理员。

## 2. 用户角色

| 角色   | 说明                 | 核心权限                                                                      |
| ------ | -------------------- | ----------------------------------------------------------------------------- |
| 管理员 | 校区负责人或运营人员 | 管理老师、班级、学生、家长绑定、流程模板、报表                                |
| 教师   | 班主任或助教         | 查看负责班级、流程打卡、教学记录、作业管理与批改、发布通知/任务并跟进回执、家校沟通 |
| 家长   | 学生监护人           | 查看绑定孩子动态、提交作业、查看反馈，查看并确认通知/任务，与老师沟通             |
| 学生   | 业务对象，不登录     | 被家长绑定、被老师记录                                                        |

## 3. MVP 范围

第一版建议只做可运营闭环：

1. 管理员维护老师、班级、学生、家长绑定关系。
2. 教师登录后看到工作台和今日班级。
3. 教师完成一日流程打卡。
4. 教师发布成长反馈或教学记录。
5. 家长登录后查看绑定孩子的今日成长。
6. 家长提交作业，教师查看并批改。
7. 教师向班级发布通知或家长任务，家长查看确认，教师查看逐位回执。
8. 家长和老师进行家校沟通。

## 4. 家长端

正式工程目录：`apps/parent-miniapp`

页面：

- 首页：孩子状态、今日成长、作业提醒、老师反馈。
- 作业：查看作业要求、提交文字或图片、查看批改反馈。
- 成长：出勤、作业、错题、流程、反馈的统一时间线。
- 沟通：通知/任务的查看确认、消息列表和聊天详情。
- 我的：家长资料、孩子绑定、联系电话。

## 5. 教师端

正式工程目录：`apps/teacher-miniapp`

页面：

- 工作台：今日课程、待办事项、快捷入口。
- 备课：教案计划、授课准备。
- 教研：听课评课、教学研讨、教师培训。
- 教学：教学记录、作业管理。
- 流程：一日流程打卡。
- 通知与任务：从工作台进入，向班级发布并查看家长回执。
- 消息与聊天：查看家长会话、进入聊天详情并回复。

## 6. 管理后台

正式工程目录：`apps/admin-web`

模块：

- 老师管理
- 班级管理
- 学生管理
- 家长绑定
- 流程模板管理
- 作业与成长记录查看
- 出勤与流程报表
- 审计日志查看

## 7. 历史原型

历史静态原型已归档保留为视觉和交互参考，不参与当前正式工程构建：

- `archive/apps/parent-app`
- `archive/apps/teacher-app`
- `archive/apps/website`

后续正式开发以 `parent-miniapp`、`teacher-miniapp`、`admin-web` 和 `api` 为主。

历史原型中的固定数量、静态活动、模拟上传和只显示提示的按钮不属于已完成功能。正式小程序只能使用真实 API 数据，并应按 `docs/ui-development-path.md` 逐页迁移原型中的有效信息架构和视觉语言。

## 8. 当前页面完善优先级

当前暂停微信登录生产化，先完成正式小程序的页面与业务功能：

1. 双端首页与统一视觉基线。
2. 教师教学记录、学生成长反馈和流程页完善。
3. 家长成长、作业和“我的”页面完善。
4. 通知、消息和聊天体验完善。
5. 新增真实的教师备课、教研数据与页面。
6. 补齐管理后台查询与配置入口。
7. 完成全页面、弱网、空数据和真机适配验收。

详细范围、验收标准和执行顺序见 `docs/ui-development-path.md`。
