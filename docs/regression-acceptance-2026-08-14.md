## 关键验证点

1. **生产模式生效**：`/auth/dev-login` 返回 403；`/api/health` 返回 `version=ac40fbc...`、`database=ok`、`fileStorage=local`。
2. **权限隔离正确**：管理员 token 访问教师端/家长端接口均被 403 拒绝；无 token / 伪造 token 均 401。
3. **业务规则生效**：删除教师/家长/学生前必须先将状态置为停用/结业，违反时接口返回明确的业务错误（400 + 中文提示），数据未被误删。
4. **DTO 校验生效**：手机号格式（`/^1\d{10}$/`）、监护人必填 `relation`、非法 base64 等均被 400 拒绝，错误格式统一为 `{ error: { code, message, requestId } }`。
5. **审计追踪完整**：一次回归产生 53 条审计记录，可在后台 `audit-logs` 查询到每次变更操作。
6. **文件链路可用**：base64 上传 → 生成 URL → 无需鉴权公开读取成功；无 token 上传被拒绝。
7. **CORS 白名单生效**：`http://localhost:8080` 获得授权，`http://evil.example.com` 无 ACAO 头。
8. **请求追踪**：所有响应带 `x-request-id`。

## 已知限制（非缺陷）

- 教师端/家长端的功能链路（登录、工作台、打卡、消息等）在**生产模式**下只能通过微信登录（`/auth/wechat-login`）使用，需要正式 AppID/AppSecret 后才能验收；开发模式下的自动化验证已由 CP-24 脚本覆盖并通过。
- 文件存储当前为 local 驱动，S3 驱动需配置 `STORAGE_DRIVER=s3` 后另行验收（deploy/.env.example 已预留）。
