# 教师培训 MVP 试运行、上线与回滚手册

本手册对应《锐之博教师培训模块 MVP 产品需求规格说明书》v1.1。首版不迁移历史培训数据，不建设课程审核发布与版本回滚体系；所有培训逾期、安全到期和复训提醒均不限制其他业务功能。

## 1. 上线前技术检查

1. 先完成数据库和文件存储备份，并按 `docs/backup-and-restore.md` 保留至少 30 个每日备份。
2. 使用 `pnpm verify:production-config` 校验生产配置。`TRAINING_MEDIA_SIGNING_SECRET` 必须为独立强密钥，不能与 JWT 密钥相同；临时媒体地址有效期应在 60～1800 秒之间。
3. S3/MinIO 必须配置独立的 `S3_TRAINING_PRIVATE_BUCKET`，且不能与公开素材桶相同。该桶不得配置匿名读策略。
4. 使用 `pnpm --filter @ruizhibo/api exec prisma migrate status` 确认迁移状态，再通过既有发布流程运行 `prisma migrate deploy`。生产环境不要运行开发 seed。
5. 迁移只保留默认管理员的培训管理授权；`practical_confirm` 和 `safety_confirm` 必须按责任人显式授予。课程维护要求全局 `training_manage`，校区级培训管理、实操确认和安全确认均按授权校区校验，不得用前端入口隐藏代替服务端授权。
6. 依次通过全仓类型检查、构建、培训规则测试、培训接口验证、校区隔离验证、功能开关验证、文件存储驱动验证和容量基线验证。
7. 在 Chrome、Edge 和微信开发者工具/真实手机各完成一次课程学习、续播、后台暂停、测验、实操、安全确认和受保护媒体访问检查。

## 2. 业务内容准备清单

业务方应为固定七门课程分别指定内容负责人和最终确认人，并准备：课程简介、适用对象、预计时长、最低有效学习时长、按顺序排列的章节、图文正文、图片、H.264/AAC 编码 MP4（画面自带字幕）、题库、答案、解析、及格分和尝试次数。

固定顺序及额外要求如下：

1. 校区文化：课程内容和测验。
2. 薪资待遇：课程内容和测验。
3. 晋升机制：课程内容和测验。
4. 带班流程：课程内容、测验、实操检查项、通过标准和带教责任人。
5. 课堂管理：课程内容、测验、实操检查项、通过标准和带教责任人。
6. 家校沟通：课程内容、测验、实操检查项、通过标准和带教责任人。
7. 安全管理：课程内容、测验、实操检查项、通过标准、安全确认责任人和复训责任人。

图片仅使用 JPG、PNG 或 WebP，默认单文件不超过 10 MB；视频默认单文件不超过 500 MB。系统不提供字幕生成、视频转码或下载入口。

## 3. 推荐试运行流程

1. 初始保持所有校区培训开关关闭，先配置并核对七门课程。
2. 选择一个校区和 5～10 名教师，确认管理员、带教负责人和安全确认人的校区权限。
3. 先为测试教师布置一轮完整培训，再覆盖批量布置、逾期、终止、离职终止、单门重学、免修、重新布置、安全撤销和自动复训。
4. 核对后台八项统计、筛选、待办、教师详情、历史轮次、审计记录和 Excel 导出。
5. 核对教师端线性解锁、最低时长、视频 90% 有效观看、续播、倍速、后台暂停、测验、实操结果、反馈、资料库和到期提醒。
6. 试运行结果经业务、运营、校区和技术共同确认后，再逐校区开启。每次开关变更必须填写原因并保留审计记录。

## 4. 运行观察

教师培训使用现有标准运行日志，不建设专门告警系统。试运行期间重点观察接口 4xx/5xx、定时任务失败、受保护媒体 403/404/5xx、视频 Range 请求、培训任务创建冲突、Excel 导出耗时和数据库连接情况。

建议每天核对一次逾期提醒与安全 T-7 复训生成情况。容量基线以 10 个并发用户、210 次请求、零失败为当前验证结果；正式放量前应在目标环境重复验证，并以现网常规接口基线的 1.5 倍作为性能比较依据。

## 5. 无删数回滚

1. 发现高影响问题时，首先在管理后台关闭对应校区功能开关并填写原因。关闭后教师端培训入口与培训业务请求停止开放，既有培训任务、快照、学习记录、确认记录和审计数据全部保留。
2. 按既有应用发布流程回退 API、管理端和教师端版本。培训迁移以新增表、字段和约束为主，旧版本不会依赖这些对象。
3. 已产生业务数据后不要执行迁移目录中的 `down.sql`，也不要删除培训表。只有在尚未启用、无任何业务数据且已完成备份时，才可由数据库负责人评审后按迁移倒序使用回滚脚本。
4. 回滚后验证教师、家长和管理员原有功能，并确认培训数据计数未变化。问题修复后重新执行全套验证，再按单校区灰度开启。

## 6. 备份恢复演练

数据库与培训私有媒体桶必须作为同一恢复点管理。至少在试运行前和正式放量前各完成一次隔离环境恢复：恢复数据库、恢复私有媒体对象、校验七门课程快照与学习记录数量、随机打开受保护图片/视频、验证 Excel 导出和审计链。恢复演练不得覆盖当前开发或生产数据库。

## 7. 首版明确不做

不迁移历史培训数据；不提供独立审核发布、版本回滚、多设备学习冲突专项处理、视频或图片下载、截屏或抓取防护、字幕、转码、培训专项告警、反馈处理状态，也不允许管理员手工标记课程完成或清空式重置整套培训。
